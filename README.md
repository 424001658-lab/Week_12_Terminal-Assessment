Week 12: Milestone 2 (Midterms) — Dart Logic Practical & Written Walkthrough

This repository contains the complete submission package for Milestone 2 (Terminal Assessment 2). The package combines Dart fundamentals, object-oriented programming (OOP) principles, mixins, interfaces, and asynchronous programming (async/await) developed through Weeks 7 to 11 into a single, cohesive executable console application.

The primary objective is to demonstrate strong structural logic, sound code architecture, and clear written reflection explaining the architectural choices behind the implementation.

Features & Concepts Implemented

Variables & Data Structures (Weeks 7–8): Demonstrates strong typing, arithmetic operations, collections (List), and control structures.

Encapsulation & Validation (Week 9): Implements getters, setters, and operational validation.

Object-Oriented Programming & Mixins (Week 10):

Inheritance: Vehicle base class extended by Car and ElectricScooter.

Interface Contracts: Maintainable abstract class enforcing implementation contracts.

Mixins: Logger mixin providing reusable execution logging across classes without multiple inheritance.

Asynchronous Programming (Week 11): Implements Future and async/await syntax to run simulated background processes (diagnostics) without blocking main thread execution.

Inline Documentation (Week 12): Comprehensive comments on classes, constructors, methods, and asynchronous operations explaining what the code does and why it was designed that way.

How to Run the Code

Option 1: Running in DartPad (Online)

Open DartPad.

Copy the entire contents of main.dart.

Paste the code into the DartPad editor.

Click the Run button to view the execution output in the console panel.

Option 2: Running via Local Dart SDK

Ensure the Dart SDK is installed on your machine.

Clone or download this repository.

Open your terminal or command prompt in the project root folder.

Execute the program using:

dart run main.dart
